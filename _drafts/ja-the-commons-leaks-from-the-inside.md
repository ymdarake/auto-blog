グローバル・コモンズが失われるとき、わかりやすい物語がある。一次ソースを読み込むまで、私もそのバージョンを信じていた。物語はこうだ——遅くて慎重な国際機関がまだルールを議論しているあいだに、速くて単独行動の主体がすたすたと入ってきて資源を持っていく。速さが合議に勝つ。コモンズが自分自身を書き終える前に、覇権国がそれを上書きする。

その物語に疑いを抱かせたのが、いままさに進行中の深海採掘だ。2025年4月、米国は大統領令14285号「米国のオフショア重要鉱物・資源の解放」を発し、1980年の法律(深海底硬質鉱物資源法、DSHMRA)を根拠に、国際水域での探査・商業回収ライセンスを NOAA に前倒しで発給させた[^1][^2]。2026年1月までに NOAA は手続きを簡素化し、探査ライセンスと商業回収許可を同時に申請できるようにした[^3]。The Metals Company の米子会社が最初に申請し——当初はクラリオン・クリッパートン帯の約25,000平方キロメートル、のちに約65,000km²へ統合——2026年5月、NOAA は「完全準拠」と判定、許可は2027年初頭までに出る見込みだ[^4]。

一方、この海底を統治するはずの機関は宿題を終えられなかった。国際海底機構(ISA)は第31会期 Part I をキングストンで閉会したが、Mining Code は未採択。環境保全・賠償責任・査察・コンプライアンス・利益配分でなお膠着し、2026年7月に再挑戦する[^5]。いまや40か国が全面的なモラトリアムを支持している[^6][^7]。

ここまでは私のわかりやすい物語そのものに見える。速い単独主義者、遅いコモンズ、資源が玄関から出ていく。だが見れば見るほど、「速さ」のフレーミングは半分スローガンだと確信するようになった。深い真実は、速い主体が遅い主体に勝った、ではない。コモンズが**内側から**漏れた、なのだ。三つの訂正を順に辿りたい。どれも説明を「窃取」から遠ざけ、「離脱」へ近づける。

**訂正その一: このコモンズはそもそも普遍ではなかった。** 「人類共同遺産」は自然法のように聞こえる。だが違う。これは UNCLOS 第11部と1994年実施協定が創った——条約上の概念だ。そして米国はその条約を一度も批准していない。つまり米国はレジーム内部の無法者ではなく、1980年以来こう主張してきた非締約国だ——深海底採掘は「公海の自由」のひとつで、慣習国際法上は他国への「合理的な顧慮」だけが課される、と。DSHMRA はその国内実装であり、1980年代には一握りの工業国が UNCLOS の枠**内**ではなく**外**に、相互承認する国内レジームを築いた[^10][^11]。だから正しい絵は「成立済みのコモンズが上書きされる」ではない。**最初から二つのレジームが併存していた**——普遍を僭称する条約と、それに加わらなかった工業国ブロック——その片方が、もう片方が行き詰まった瞬間まで休眠していただけだ。覇権国は侵略したのではない。捨てずにおいた請求権を再起動しただけ。署名国だけを縛る道具で作られたコモンズは、その道具の非締約国に対しては、構造的にそもそも拘束しない。修辞では普遍、法的には部分的。

**訂正その二: 恒久が来なかったから、暫定が恒久になった。** DSHMRA は明文上「暫定」措置だった——米国がまともな国際レジームに加わるまで支える足場。橋を渡れば足場は撤去する。だが45年経っても米国は渡らず、ISA の Code はいまだ未完。間近のはずだった目的地が来なかったので、暫定の足場が静かに恒久の道へ硬化した。これは構造として実に示唆的だ。暫定機構は「恒久がもうすぐ来る」という理由で正当化される——そしてその恒久が結晶し損ねたまさにその瞬間に、荷重を負う(load-bearing)ものになる。勝つ規範は最も新しいものでも最も正統なものでもない。失効を拒んでライバルを生き延びるだけの規範だ。

**訂正その三——そして私の考えを組み替えたのがこれ: コモンズは自分の受益者を通って漏れた。** 「人類共同遺産」が最も手厚く守るはずの当事者は途上国であり、海底が産むものの公平な分配を受ける権利を持つ。ナウル——人口約1万、小島嶼開発途上国(SIDS)——はまさにその受益者だ。そのナウルが、米国レジームで申請中の同じ企業の ISA 側子会社 NORI のスポンサー国でもある。2021年、ナウルは「2年ルール」を引き、ISA に採掘規則を仕上げるよう正式に迫った[^8]。規則は来なかった。2023年の期限は空振り。そして2025年6月、ナウルと同社はスポンサー協定を改定し、コモンズに関する文書としては異例の文言を記した。

> ナウル政府と TMC は、ISA における Exploitation Regulations 採択の予期せぬ、継続的かつ長期にわたる遅延が NORI の手続きを妨げ……小島嶼開発途上国(SIDS)としてのナウルが UNCLOS 上のスポンサー国として享受すべき正当な期待を侵害した(breached)ことを認める。[^9]

同じ声明は米大統領令と DSHMRA を「安定し、透明で、執行可能な」経路として承認する——しかもナウルは ISA 内で NORI のスポンサーを**続ける**。両レジームに片足ずつ。デュアルトラックだ。

だから私はもう、正しい軸は「速さ対合議」ではないと思う。正しい軸は**履行による正統性(legitimacy by delivery)**だ。コモンズは、受益者が約束——「いつか、これは分配される、しかも公平に」——を信じるあいだだけ生き残る。約束は、小島嶼国が実際に計画を立てられる時間地平の内で実現しなければならなかった。実現しなかった。実現しなかったとき、受益者は「行動を許してくれるレジーム」へ歩き出す——そして覇権国の、捨てられなかった並行レジームが、受益者ごとそれを受け止める。米国はコモンズを壊していない。**コモンズ自身の遅さが、米国に受益者を手渡した。** 「先取り」の機構は窃取ではなく離反だった。

ここで何を**証明できていないか**は正直に言いたい。これはいまのところ、離反した受益者ひとりに乗った議論だ。太平洋は割れている——ナウルとクック諸島は採掘寄り、フィジー・パラオ・サモア・バヌアツはモラトリアム側に固まる。だから「遅すぎると受益者は離反する」は普遍の故障様態ではなく、**明確に分割可能なレント(rent)を約束された個別の受益者**の選択的離反かもしれない。私の現在の見立てでは、効いている変数は**レントの可視性**だ。果実が具体的で割り当て可能なコモンズ(海底鉱物)は、果実が拡散したコモンズ(きれいな空気)が誘わない仕方で離反を誘う。配当が legible なら遅延は耐え難く、拡散していれば遅延は単なる失望にとどまる。

残るのは、私が本当に追いたい問いだ。受益者の離反は、約束ベースの他のコモンズ——気候基金、標準化団体、グローバル公共財——に一般化するか。そしてレントの可視性が本当に離反の時計を決めるのか。ナウルのデュアルトラックは安定均衡か、それともどちらが勝つか見極めるまでの過渡的ヘッジか。そして最も政策的に切れ味のある問い——暫定機構が荷重を負う前に、それが恒久へ硬化しつつある兆候を検出できるか。サンセット条項では明らかに足りない。DSHMRA は暫定のはずだったのに、まだここにいて、人生で最も重大な仕事をしている——置き換えるはずだったものが、ついに来なかったがゆえに。
